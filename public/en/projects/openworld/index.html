Volumetric clouds

Sampling a 3D volume texture with wind

uvw=PworldS+DwindVwindt \mathbf{uvw} = \frac{\mathbf{P}_{\mathrm{world}}}{S} + \mathbf{D}_{\mathrm{wind}}V_{\mathrm{wind}}t
  • PworldP_{world} is the world-space position of the current ray-marching sample.
  • SS sets the spatial scale of the cloud noise.
  • DwindD_{wind} is the wind direction.
  • VwindV_{wind} is the wind speed.
  • tt is time.
  • uvwuvw gives the three coordinates used to sample the volume texture.

Culling by height

The height function is

H(x)=(1−ex)(1−e1−x) H(x)=(1−e^x)(1−e^{1−x})

The custom material node evaluates it as follows.

float x = saturate(NormAltitudeInLayer);

float a = 1.0 - exp(x);
float b = 1.0 - exp(1.0 - x);

return a * b;

The resulting density is computed as

ρ=saturate⁡[N−(1−H(h))B] \rho = \operatorname{saturate} \left[ N-\left(1-H(h)\right)B \right]
  • NN is the base 3D noise.
  • H(h)H(h) is the height-dependent density function.
  • BB is the height bias.
  • ρrawρ_{raw} is the raw density after the height adjustment.

Bending the grass

The material uses RotateAboutAxis to bend each blade.

  • Rotation axis: take the cross product of the Z axis and the vector from the player to the grass.
  • Pivot Point: the base of the blade.
  • Position: the absolute position.
